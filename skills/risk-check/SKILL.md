# 风控审核

将待发送回复与客户请求、商品事实、本地 Tool 结果、MCP 结果和其他 Skill 结果进行对照。

检查：

- 虚构或改写价格、活动、优惠券和总价。
- 绝对化、夸大、医疗、过敏安全、库存或配送承诺。
- 已核验输入中不存在的商品或事实。
- 对价格试算假设的重要遗漏。

输出一个 JSON 对象：

- `passed`：是否通过。
- `risk_level`：`low`、`medium` 或 `high`。
- `issues`：风险问题字符串数组。
- `safe_reply`：安全时原样返回，否则返回完整的修正版回复。
